# IT-Куб: полноценный WordPress сайт под набор

Репозиторий содержит готовый сайт IT-Куба с развёртыванием через Docker и собственной WordPress-темой.

## Что внутри

- Тема: `wordpress/wp-content/themes/it-cube-enrollment`
- Скрипт первичной установки WordPress: `scripts/setup-wordpress.sh`
- Docker-окружение: `docker-compose.yml`
- SQL-скрипт (опционально): `db/it_cube_homepage_setup.sql`
- Превью структуры главной: `docs/preview/homepage-structure-preview.svg`
- Чек-лист замены контента: `docs/content/replace-before-publish.md`

## Что уже реализовано

- Полноценная главная страница под набор:
  - hero-блок с CTA;
  - о программе, навыки, кому подойдёт, преимущества;
  - блок «Как проходит обучение»;
  - блок новостей (автоматически показывает последние посты);
  - FAQ;
  - финальный CTA.
- Контентные шаблоны:
  - страницы (`page.php`);
  - список новостей (`home.php`);
  - отдельная новость (`single.php`);
  - архивы (`archive.php`);
  - 404 (`404.php`).
- Навигация:
  - главное меню;
  - меню в футере;
  - мобильное меню (JS).
- Админ-настройки темы:
  - `Внешний вид -> Настройки IT-Куб`;
  - контакты в футере;
  - ссылка на форму записи;
  - SEO/OG параметры.
- SEO/OG:
  - `description`, `keywords`, `robots`, canonical;
  - Open Graph и Twitter Card;
  - защита от дублирования мета-тегов при наличии Yoast/Rank Math.

## Быстрый старт (локально)

Требования:
- Docker Engine с поддержкой `docker compose`.

1. Скопируйте переменные окружения:

```bash
cp .env.example .env
```

2. При необходимости поменяйте значения в `.env`:
   - `WP_PORT`
   - `WP_HOME`
   - `WP_ADMIN_USER` / `WP_ADMIN_PASSWORD`
   - параметры БД

3. Поднимите сайт и выполните первичную установку:

```bash
make setup
```

4. Откройте:
   - сайт: `http://localhost:8080`
   - админка: `http://localhost:8080/wp-admin`

## Полезные команды

```bash
make up       # поднять контейнеры
make down     # остановить контейнеры
make logs     # смотреть логи
make wpcli cmd="plugin list"  # выполнить wp-cli команду
```

## Как настраивать сайт после запуска

1. Перейдите: `Внешний вид -> Настройки IT-Куб`.
2. Заполните контакты, ссылку на форму и SEO/OG.
3. Добавляйте новости в разделе `Записи`.
4. Меню можно редактировать в `Внешний вид -> Меню`.

## SQL-скрипт (опционально)

`db/it_cube_homepage_setup.sql` нужен только если требуется ручная настройка через БД.
Контакты и SEO редактируются через админку.
