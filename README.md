# IT-Куб: WordPress главная под набор

В репозитории подготовлен готовый набор для главной страницы IT-Куба под новый учебный год:

- WordPress тема: `wordpress/wp-content/themes/it-cube-enrollment`
- SQL-скрипт настройки БД: `db/it_cube_homepage_setup.sql`

## Что делает тема

- Выводит структурированную главную страницу с блоками под набор:
  - первый экран с CTA и акцентами "Бесплатно", "7-18 лет", "Места ограничены";
  - блоки "О программе", "Чему учатся", "Кому подойдёт", "Преимущества";
  - финальный CTA "Записаться сейчас";
  - футер с контактами и юридической заглушкой.
- Ссылка на форму: `https://forms.gle/gV1wny8C8a`

## Быстрый запуск

1. Скопируйте папку `it-cube-enrollment` в:
   `wp-content/themes/`
2. Активируйте тему через админку WordPress
   или импортируйте SQL-скрипт `db/it_cube_homepage_setup.sql`.
3. Проверьте контакты в футере и замените заглушки:
   - `it_cube_contact_phone`
   - `it_cube_contact_email`
   - `it_cube_contact_address`

## Применение SQL-скрипта

Скрипт рассчитан на префикс таблиц `wp_`.
Если у вас другой префикс, перед запуском замените его в файле.

Пример импорта:

```bash
mysql -u USER -p DB_NAME < db/it_cube_homepage_setup.sql
```
