# Что заменить перед публикацией сайта IT-Куб

Ниже список полей и блоков, которые обязательно нужно заполнить реальными данными.

## 1) Контакты и заявка (админка)

Путь: `Внешний вид -> Настройки IT-Куб`

- `Телефон` — реальный контактный номер
- `E-mail` — рабочая почта для обращений
- `Адрес` — полный почтовый адрес площадки
- `Ссылка на форму записи` — актуальная форма приёмной кампании

## 2) SEO/OG (админка)

Путь: `Внешний вид -> Настройки IT-Куб`

- `Meta description` — итоговое описание страницы (120-180 символов)
- `Meta keywords` — 5-10 целевых фраз
- `Robots` — обычно `index,follow`
- `OG image URL` — изображение для соцсетей (рекомендуется 1200x630)
- `Twitter Card` — `summary_large_image`

## 3) Контент главной страницы (шаблон)

Файл: `wordpress/wp-content/themes/it-cube-enrollment/front-page.php`

Проверьте и, при необходимости, обновите:

- формулировки текущего учебного года/набора;
- список направлений и навыков, если программа изменилась;
- блок FAQ под реальные вопросы родителей;
- блок «Как проходит обучение» под вашу фактическую модель.

## 4) Новости

- Добавьте минимум 3 живые записи в `Записи`:
  - новость о старте набора;
  - пример проекта/достижения;
  - анонс ближайшего мероприятия.

## 5) Меню

Путь: `Внешний вид -> Меню`

- проверьте главное меню (якоря и страницы);
- проверьте футер-меню;
- добавьте пункт «Политика обработки персональных данных».

## 6) Юридические страницы (обязательно)

Создайте и добавьте в меню:

- Политика обработки персональных данных;
- Согласие на обработку персональных данных (если требуется вашей формой);
- Сведения об образовательной организации/лицензии (если нужно по регламенту).

## 7) Техническая проверка перед запуском

- проверить работу всех кнопок CTA;
- проверить отображение на мобильных (360 px и выше);
- проверить Open Graph предпросмотр ссылки;
- проверить индексацию (robots/canonical);
- проверить, что форма записи открывается без ошибок.
